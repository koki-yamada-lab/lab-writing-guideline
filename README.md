# 山田宏樹研究室の論文執筆のガイドライン

研究室メンバーが論文執筆の基礎を身につけやすいように，読むべき資料・書籍をまとめたうえで，どのように論文執筆をしていくかを説明しています．

## スライド資料

Marpを使ってスライド資料`main.md`を作っています．
