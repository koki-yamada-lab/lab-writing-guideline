## チェックリスト

- [ ] **各セクション・サブセクションの役割を明確にする**：
その節で「何を説明するのか」を一文で言えるようにする．
- [ ] **1つの節では1つの話題を扱う**：複数の論点を無理に同じ節へ詰め込まない．
- [ ] **見出しと本文の内容を一致させる**：見出しを読めば，その節で何を説明するか予想できるようにする．
- [ ] **セクション間の役割を分離する**：
よくある失敗例は，提案手法のセクションなのに従来手法の説明を長々入れることです．従来手法の話は別のセクションで話すべきです．
- [ ] **同じ内容を複数の節で繰り返さない**：説明する場所を一箇所に決め，必要なら他の節から参照する．
- [ ] **論理的な順序で並べる**：後の節が前の節を前提として読める順序にする．
- [ ] **階層の粒度をそろえる**：同じレベルのサブセクションには，同程度の重要度・粒度の内容を置く．
- [ ] **細かく分けすぎない**：数段落しかない内容のためにサブサブセクションを大量に作らない．
